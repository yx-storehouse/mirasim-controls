## 使用原来的入口

1. 等待正在运行的任务结束，完成Mirasim自身的0.0.828更新。
2. 从系统托盘完全退出Mirasim，然后双击原来的 **01-安装或修复.bat**。
3. 确认窗口显示补丁版本 **4.5.1**、目标版本 **0.0.828**，安装完成后重新打开Mirasim。

补丁版本没有变化是正常的。Git自动更新入口会继续检查最新提交，无须新的ZIP。若之前因为文件占用出现“上次安装中断”，完全退出后重新运行同一个BAT即可自动恢复并重试。
