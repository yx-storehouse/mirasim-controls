# Mirasim 0.0.840：4.5.3 适配说明

0.0.840的shell ABI为243。其前端重写了紧凑输入栏的宽度计算，并更新下拉菜单关闭行为；旧4.5.2会在写入前停止。**4.5.3适配新前端，继续使用原来的Git自动更新BAT。** 后端功能和已有Claude Fast认证修复保持。

## 新版布局适配

新版根据DOM实测宽度调整输入栏密度，取代旧字符预算逻辑，并增加原生右侧上下文区域。补丁为这种已审核结构使用独立分支：Claude两个开关放在被测输入栏之外的第二行，Codex速度控件沿用行内布局，保留原生右侧内容、布局参数和测量逻辑。旧版仍使用原来的预算与布局分支。

仅在新布局生成的Codex组件中，速度值、语言或父布局回调变化会调用原生测量函数，以覆盖待保存值、确认值和失败回退后的文字宽度变化。未新增Observer或全局事件监听；公共模板保持不变。

下拉菜单新增锚点隐藏时关闭、捕获阶段pointerdown处理和分组标题样式。value、onChange、disabled和键盘选择契约保持；补丁继续复用完整的原生Select组件。

## 安装方式

1. 等任务结束，完成Mirasim自身的0.0.840更新。
2. 从系统托盘完全退出Mirasim，双击原来的 **01-安装或修复.bat**。
3. 确认窗口显示补丁 **4.5.3**、目标 **0.0.840**，安装完成后重新打开Mirasim。

不需要新的ZIP或BAT。运行中的旧进程不会自动加载补丁；安装器不结束任务，文件占用时会回滚并提示退出后重试。
