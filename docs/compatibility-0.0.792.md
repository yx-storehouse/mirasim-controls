## 更新后怎么使用

完成Mirasim更新后，从系统托盘退出Mirasim，再运行原来的 `01-安装或修复.bat`。它会检查仓库更新，并为792重新应用三项控制。成功后重新打开Mirasim，无须重新下载固定启动器。

本次验证使用隔离的792程序文件，未替用户执行Mirasim升级。UI保存使用本地模拟应答，不代表上游加速效果已实测。
