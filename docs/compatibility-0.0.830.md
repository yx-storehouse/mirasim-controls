# Mirasim 0.0.830：4.5.2 适配说明

0.0.830的shell ABI为234。它在Claude中转配置中新增原生环境默认值，改变了BYOK适配器结构；旧4.5.1补丁会在写入前停止，并报告 `Native Claude API authentication (byok, Zss) logic changed; manual adaptation is required`。**4.5.2支持这个新结构，继续使用原来的Git自动更新BAT。**

## 本次变更

新版本增加 `CLAUDE_CODE_DISABLE_NONESSENTIAL_TRAFFIC="1"`，由Mirasim自身合并到协议桥和非官方原生中转连接的环境中。4.5.2保留这项原生行为，并校验新增常量的绑定和值；不只放行一个新函数指纹。

此前Claude Fast的API Key认证修复、Fast与Ultracode的独立开关及Codex速度选择继续保留。前端结构与828一致，无需修改前端运行脚本。未知或异常结构仍会停止安装并生成兼容报告。

## 使用方法

1. 等正在运行的任务结束，完成Mirasim自身的0.0.830更新。
2. 从系统托盘完全退出Mirasim，再双击原来的 **01-安装或修复.bat**。
3. 确认窗口显示补丁 **4.5.2**、目标 **0.0.830**，安装后重新打开Mirasim。

无需下载新的工具包。运行中的旧进程不会自动加载补丁；安装器不结束任务，文件被占用时会回滚并提示退出后重试。
