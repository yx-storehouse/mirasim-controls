# Mirasim 0.0.842 使用控制区 4.5.4

如果运行 4.5.3 时看到 `Native Claude API authentication (byok, bvs) logic changed` 和退出码 2，请等当前任务完成，从系统托盘退出 Mirasim，然后双击原来的 **01-安装或修复.bat**。启动器会拉取 4.5.4。确认目标为 **安装版 0.0.842**，看到安装完成后重新打开 Mirasim。

## 这次为什么需要适配

842 在 Claude 自定义 API 连接的启动逻辑中增加了长上下文处理。Mirasim 优先读取模型配置中大于零的 `contextWindow`，否则读取模型目录的 `contextLength`。在协议桥和第三方原生 Anthropic 接口中，当这个值大于 200,000 时，842 会把 `CLAUDE_CODE_DISABLE_1M_CONTEXT` 设为空字符串。在恰好 200,000 以及更小的窗口下，842 按原设置启动。官方原生接口有自己的启动路径。

4.5.3 会在写入程序文件前停止，因为它只识别先前审阅过的启动逻辑。4.5.4 同时核对新增函数、上下文取值来源和 200,000 阈值，在通过检查后应用已有的 Claude Fast 认证修复。Codex 速度、Claude Fast 和 Ultracode 继续使用 840 适配过的菜单和窄屏布局。

- 取自 Windows 安装版 0.0.842（ABI 245）的后端和 ASAR，其 SHA-256 均与此次兼容报告匹配。在临时目录安装和重复运行均成功。用 842 自带的 Electron 读取修改后的前端资源并核对完整性后，恢复操作逐字节还原了两个程序文件。
- 68 项仓库测试全部通过。842 的后端另验证了 24 组 Fast、Ultracode 和推理强度组合，覆盖显式窗口、模型目录回退、200,000 与 200,001 两侧的边界，以及自定义认证方式。
- 17 项前端行为检查和 21 项浏览器交互检查通过。对 12 个旧版样本的后端回归表明，4.5.4 生成的结果与 4.5.3 逐字节一致。
